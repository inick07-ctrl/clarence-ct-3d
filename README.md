# Smith Home Models

Interactive 3D models of Smith home plans: https://inick07-ctrl.github.io/clarence-ct-3d/

- `#smith-01` opens Smith 01 (Clarence Ct U-plan), and `#smith-02` opens Smith 02 (modern farmhouse with pool).
- To add a home, create `models/smith-03.js` using the same format as `models/smith-02.js`, then add it to `models/registry.js`. A tab appears automatically.
